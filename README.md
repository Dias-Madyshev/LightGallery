# Photo Gallery

A simple and responsive photo gallery project where you can:

- View images in a popup
- Navigate between images with left/right arrows
- Close the popup with a click

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## How to Use

1. Download or clone the repository:
git clone https://github.com/your-username/photo-gallery.git

2. Open `index.html` in your browser.
